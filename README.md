# Student Attendance and Grade Manager

## Introduction

Student Attendance and Grade Manager is a Python-based project developed for CSE1021 Introduction to Problem Solving and Programming.

The project provides a simple menu-driven system for managing student information, attendance, marks, grades, and reports.

## Features

- Add student
- View all students
- Search student
- Add attendance
- Add marks
- Calculate grade
- Generate student report
- Input validation
- Duplicate roll number checking

## Technologies Used

- Python
- Visual Studio Code
- Git and GitHub

## Project Modules

| File | Purpose |
|---|---|
| `main.py` | Controls the main menu and program flow |
| `data.py` | Stores student data |
| `student.py` | Manages student records |
| `attendance.py` | Manages attendance |
| `marks.py` | Manages marks and grades |
| `reports.py` | Generates student reports |
| `validation.py` | Validates input |
